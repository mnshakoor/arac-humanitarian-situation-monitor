TRANSPARENCY
Methodology
Core rules
  • Use date.original for humanitarian publication trends.
  • Use primary_country for country rankings to reduce multi-country double counting.
  • Use published ReliefWeb records for public analytical displays.
  • HISI measures information-system intensity and diversity, not humanitarian severity.
  • Source diversity is not equivalent to independent corroboration.
  • Country profiles are enriched for the highest-volume countries to conserve ReliefWeb API quota.
